# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in `bipkit-python`, please **do not** open a public GitHub issue.

Report it responsibly to **support@bipware.co.za** with:
- A description of the vulnerability and reproduction steps
- Affected SDK version and Python runtime version
- Any relevant proof-of-concept details

We will acknowledge receipt within 2 business days and coordinate a fix and disclosure timeline.
